# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/darshansatpathy/ai-platform-reference-architecture/security/advisories/new)
for this repository. You should get an acknowledgement within three working days.

## Scope

In scope: the `archfit` tool and the architecture it checks, in particular a flaw in a fitness function that lets an unsafe design pass. Out of scope: the systems an adopter builds from this reference.

## Operating it safely

- This repository describes an architecture; it contains no credentials, customer data or real prices. Do not add them.
- The catalog's SLOs, RTOs and unit prices are design targets or placeholders. Replace them with measured and contracted values before relying on them.
- Do not publish real hostnames, tenant identifiers or internal contact details in the catalog.

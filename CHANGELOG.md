# Changelog

All notable changes to this project are documented here. The format follows

## [0.1.0] - 2026-11-13

### Added
- Architecture catalog of 27 components in 6 layers, with owners, tiers, SLO targets, data classes and dependencies.
- `archfit` with fitness functions for layering, cycles, SLO feasibility, data-classification flow, egress, tier inversion, recovery objectives, ownership, telemetry and cost tags.
- Expiring, reasoned waivers; generated component, dependency, data-flow, SLO, ownership and FinOps documents with a freshness check.
- Nine ADRs, a risk register, an operating model, an adoption roadmap and a runbook per operated component.
- Unit-economics model with placeholder inputs.
